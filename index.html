Hinge lab · not the full handkerchief

Learn the fold, not the whole piece

The handkerchief visualisation stands on one idea: a fold is a hinge — a 180° rotation about a crease that already sits in the cloth. These pages are small demos of that idea. They are not a rebuild of the 4×4 story.

Read the study list, then open the work-in-progress file so you can see the usual mistake. Then open the finished file. The JavaScript is written slowly on purpose, with names and comments for the words mathematicians and CSS use.

Reading (in this order)

  1. Wikipedia · Reflection (mathematics) — the map x ↦ 2a − x. That is what a 180° hinge looks like from above.
  2. Wikipedia · Involution — a function that is its own inverse. Fold twice and you are back. That is why we can store a fold as 0 or 1.
  3. MDN · Using CSS transforms — the camera (perspective), 3D children (transform-style: preserve-3d), and that a transform list is applied right to left.
  4. MDN · transform-function — the catalogue of translateX, rotateY, and friends.
  5. MDN · rotateY() and translateX() — the two functions inside a vertical hinge.
  6. MDN · perspective, transform-style, backface-visibility — the three properties that make a two-sided card in CSS, without WebGL.
  7. MDN · 3D-specific CSS properties — same article, the 3D section. Optional once the pages above make sense.

You do not need WebGL, Three.js, or a physics engine. The cloth never bends.
